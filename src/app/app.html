Angular Stuff

A collection of basic components that each use various Angular specific functionality.

How the Stopwatch works

Built using Angular's reactive Signals (signal()) to hold the time state. Event binding ((click)) in the template triggers methods that mutate the signal via .update() and .set().

How the Quiz works

Relies on Angular Signals to track the current question index, score, and finished state. The template leverages Angular's built-in control flow (@if and @for) to dynamically render questions and options.

How the Password Gen works

Uses an Angular Signal to store the generated password string. Event binding ((click)) fires the logic, mutating the signal which Angular automatically reflects in the DOM.

How the Chat UI works

Manages a message list using a Signal array. The template uses the @for control flow block to iterate, a template reference variable (#input) to grab user input, and event filtering ((keyup.enter)) for submission.

How the Search UI works

State is driven entirely by Signals. Uses @if blocks to conditionally display loading/error messages. Utilizes property binding ([src]) for the avatar and updates the query signal using the (input) event.

How the Voting App works

State is managed centrally using an injectable Service (PollStore) leveraging Angular Signals and computed() for derived state. The component uses inject() to access the store and ngModel for two-way data binding on new options.

How the Notes App works

Uses Angular Signals to store notes and search state. A computed() signal dynamically filters the notes based on the search query. An effect() automatically persists notes to localStorage whenever the state changes.
