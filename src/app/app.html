Angular Stuff: Showcase Portfolio

A comprehensive collection of standalone components demonstrating core modern Angular capabilities: Signals, RxJS Observables, Reactive Forms, Dependency Injection, and Lifecycle Hooks.

How the Stopwatch works

Built using Angular's reactive Signals (signal()) to hold millisecond state and a Computed Signal (computed()) for formatted time output. Unlike regular functions that execute on every change detection cycle, computed() is lazily evaluated and memoized—it only recalculates when its underlying dependency signal changes. Event binding ((click)) triggers methods that mutate the signal via .set() and .update().

How the Quiz works

Tracks game state with multiple Signals (currentIndex, score, and finished). The template leverages Angular's built-in Control Flow (@if and @for) which replaces legacy structural directives (*ngIf / *ngFor) with a cleaner, faster compiler syntax that eliminates unnecessary wrapper elements and improves build-time type checking.

How the Password Gen works

Demonstrates atomic state updates using a writable Signal (password = signal('')). Clicking the generate button triggers cryptographic randomness in TypeScript and updates the signal via .set(). Angular automatically notifies only the specific DOM text node bound to password(), enabling fine-grained template reactivity without re-evaluating the entire component tree.

How the Chat UI works

Manages an array of chat messages using an immutable signal update pattern (this.messages.update(list => [...list, msg])). The template utilizes a Template Reference Variable (#input) for direct DOM element access without needing two-way binding, paired with Angular event filtering ((keyup.enter)) for keyboard submissions and @for with tracking for optimal DOM recycling.

How the Search UI works

Demonstrates asynchronous state management where multiple signals track distinct states of an external request: query, user, loading, and error. The component uses property binding ([src], [disabled]) and conditional @if rendering to display loading spinners, error alerts, and retrieved user profiles with zero UI flicker.

How the Voting App works

Showcases enterprise architecture with an Injectable Singleton Service (PollStore) decorated with @Injectable({ providedIn: 'root' }). The component accesses this store via Angular's modern functional inject(PollStore) API instead of constructor injection. The store encapsulates poll options, vote increments, and a computed() signal deriving total votes across all options.

How the Notes App works

Highlights Angular's effect() API. While computed() is intended strictly for pure, side-effect-free derivations, effect() is designed for operations that communicate with external APIs, like serializing note state to localStorage. The effect automatically tracks dependencies inside its injection context, synchronizing data to browser storage with environment safety checks for SSR/testing compatibility.

How the Mini Cart System works

Combines writeable cart state with derived aggregates using computed() to calculate both total item count and currency sum (via array reduce). An effect() automatically mirrors cart state into localStorage, while component methods enforce business rules such as item limits (maximum 10 items) and removal logic.

How the Traffic Signal works

Demonstrates state automation and Component Lifecycle Hooks (ngOnInit and ngOnDestroy). The active light and countdown timer are managed with signals. In ngOnInit, a periodic timer triggers light cycles; in ngOnDestroy, the timer interval is cleared using clearInterval(), preventing critical browser memory leaks when the component unmounts.

How the Live Search works (RxJS)

Showcases asynchronous reactive programming using RxJS Observables and Operators. Keystrokes from a FormControl emit values through debounceTime(300) to throttle rapid typing, distinctUntilChanged() to ignore non-character keypresses, and switchMap() to cancel stale in-flight search requests when a new query arrives (eliminating race conditions). The template renders results declaratively using the async pipe, which automatically manages subscriptions and unsubscribes when the component destroys.

How the Registration Form works

Demonstrates enterprise Reactive Forms using FormBuilder, FormGroup, and Validators. Validation rules (required, minLength, email, requiredTrue) remain strictly encapsulated in TypeScript rather than the template. Validation messages render dynamically only when controls are dirty or touched to ensure a clean user experience. A custom cross-field group validator (passwordMatchValidator) validates that password and confirm password fields match in real-time before submission.

How the Digital World Clock works

Pairs an Angular Signal (currentTime = signal(new Date())) with lifecycle-managed interval updates. The template utilizes standard JavaScript Intl.DateTimeFormat internationalization APIs to dynamically compute and display exact times across multiple world time zones (UTC, New York, London, Tokyo) with zero external third-party date library overhead.
